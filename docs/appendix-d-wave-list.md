# Appendix D — AWM wave list

> **Source**: Yamaha *SEQTRAK Data List* (OS V2.00), transcribed from `reference/SEQTRAK_data_list_En_D0.pdf` by `tools/pdf-extract/wave_list.py`.
> Confidence: `from Yamaha Data List`.


The 2024 preset waveforms an AWM element can point at. The number goes into **Wave Number**, the 14-bit parameter at `41 ep 03` (`Wave Select` at `41 ep 01` chooses preset or user memory). The parameter accepts 1-4096 while only these are populated.

Machine-readable: [`../data/waves.csv`](../data/waves.csv).
