# Appendix F — Arpeggio preset list

> **Source**: Yamaha *SEQTRAK Data List* (OS V2.00), transcribed from `reference/SEQTRAK_data_list_En_D0.pdf` by `tools/pdf-extract/arpeggio_presets.py`.
> Confidence: `from Yamaha Data List`.


`ARP Template` (`31 5p 00`, and CC 27) selects one of these 16 presets. Each sets the arpeggiator's type, key mode and octave range; `ARP Type` (`31 5p 1E`) can also be set directly.

| No. | Preset Name | Type | Mode | Octave |
|---|---|---|---|---|
| 1 | Off | - | - | - |
| 2 | Up | Up | Sort | 0 |
| 3 | Up 2Octave | Up | Sort | +1 |
| 4 | Down | Down | Sort | 0 |
| 5 | Down 2Octave | Down | Sort | +1 |
| 6 | Random | Random | Sort | 0 |
| 7 | Random 2Octave | Random | Sort | +1 |
| 8 | Up / Down A | Up Down 1 | Sort | 0 |
| 9 | Up / Down A 2Octave | Up Down 1 | Sort | +1 |
| 10 | Up / Down B | Up Down 2 | Sort | 0 |
| 11 | Up / Down B 2Octave | Up Down 2 | Sort | +1 |
| 12 | Thumb Up | Slap & Pop | Sort | 0 |
| 13 | Unison | Unison | Sort | 0 |
| 14 | Chord 1 | Rhythm 1 | Sort | 0 |
| 15 | Chord 2 | Rhythm 2 | Sort | 0 |
| 16 | As Played | Up | Thru | 0 |
