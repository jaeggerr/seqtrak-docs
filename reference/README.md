# reference/

This folder is empty in the public repository on purpose. The documentation was
transcribed from two Yamaha documents, which are Yamaha's copyright and are not
redistributed here:

| File | Document |
|---|---|
| `SEQTRAK_data_list_En_D0.pdf` | *SEQTRAK Data List* (OS V2.00) |
| `SEQTRAK_user_guide_En_D0.pdf` | *SEQTRAK User Guide* (OS V2.00) |

Download them from Yamaha's SEQTRAK downloads page and put them here under
exactly those names:

<https://au.yamaha.com/en/products/music_production/music-production-studios/seqtrak/downloads.html>

Nothing in `docs/` or `data/` needs them. Only the extractors in
`tools/pdf-extract/` read them, to regenerate the transcribed appendices.

Two figures exist only as graphics in the Data List and are not transcribed:
the **DX algorithm chart** (p. 161) and the **effect block diagram** (p. 60).
